『分子間力くらいの距離』表紙・別室追加パック
================================================

このZIPは「差分アップデート」です。
既存のGitHubリポジトリの全ファイルを含むものではありません。

【重要】本文は一切含めていません。
chapters/01.txt ～ chapters/26.txt と chapters.json、現在の style.css、script.js は
削除・置換せず、そのまま使ってください。

パックに含まれるもの：
- index.html            新しいトップページ（上書き）
- reader.html           既存ビューア＋章記録用JSの読み込み（上書き）
- site-extras.css       新しいトップ／別室の見た目（追加）
- site-extras.js        「前回開いた章から」表示（追加）
- reading-progress.js   最後に開いた章の番号だけ保存（追加）
- gallery.html          ギャラリー用の器（追加、公開準備中）
- music.html            音楽用の器（追加、公開準備中）
- images/cover.webp     提供いただいた表紙写真をWebPに変換したもの（追加）
- images/og-cover.jpg  SNSでURLを共有するときの画像（追加）

【導入方法】
1. GitHubの現在のリポジトリを保全する（必要ならZIPとしてバックアップ）。
2. このZIPを展開する。
3. 上記のHTML/JS/CSSをリポジトリのルートへ、画像2枚を images/ フォルダへ置く。
4. 既存の index.html と reader.html の上書き、その他ファイルの追加をコミットする。
5. GitHub Pagesの反映後、PCとスマートフォンの両方で確認する。

【確認すること】
- 表紙が表示され、タイトルと本文紹介が読める
- 「最初から読む」で第1章が開く
- 目次から各章が開く
- 何章か開いて入口に戻ると「前回開いた章から」が出る
- 縦書き、横書き、文字サイズ、ダークモード、前章・次章が従来どおり動く
- gallery.html と music.html が開く（現在はコンテンツ公開準備中のページ）
- SNSのカード画像は反映に少し時間がかかる場合がある

【仕様上の注意】
- 「前回開いた章から」は章単位です。スクロール位置までは復元しません。
- 履歴はそのブラウザのlocalStorageに保存され、別端末には同期されません。
- gallery.html と music.html は未完成コンテンツを誤って公開しないため
  プレースホルダー表示になっています。音楽の自動再生はありません。
- 本文の文章データおよびルビ・縦中横の処理を行う既存script.jsは変更していません。
